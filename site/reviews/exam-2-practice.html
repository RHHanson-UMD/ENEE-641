A repeatable answer structure

For every algorithm-design or proof question, write these five parts in order:

  1. Model and assumptions: directed/undirected, nonnegative/real weights, input size and required output.
  2. Algorithm: state variables, initialization, data structure, transitions/loop, and reconstruction of any witness.
  3. Correctness: a precise invariant or exchange/reduction argument, base case and induction/contradiction step.
  4. Running time: operations counted separately and a justified bound (not just “fast”).
  5. Limits: unreachable states, ties, cycles, invalid assumptions, or a counterexample.

Study technique: attempt each problem without notes, then open its solution. The self-check rubric is a reflection aid, not an official score.

1. Resilient network links

18 minutes / Chapter 22

A connected undirected communication network has vertices {p,q,r,s,t,u}, with edges {pq, qr, rp, rs, st, tu, us}. A link is critical if removing that edge increases the number of connected components. Identify the critical links and design an algorithm to find every critical link in any undirected graph. State the bound for an adjacency-list representation and justify correctness.

Reveal original worked solution and failure cases
  1. For the supplied graph, rs is the only critical edge: the pqr and stu triangles each remain connected internally, but the two triangles share only rs.
  2. Run DFS in every connected component. Store discovery time d[u] and low[u], the earliest discovery reachable from u's DFS subtree using zero or more tree edges and at most one back edge.
  3. For every DFS tree edge (u,v), report it exactly when low[v] > d[u]. If low[v] ≤ d[u], a back edge reconnects v's subtree to u or an ancestor, so removing (u,v) does not separate it. Otherwise the DFS tree edge is the only connection from that subtree to the rest.
  4. Time Θ(|V|+|E|), space O(|V|) auxiliary beyond adjacency lists. A DFS forest handles disconnected inputs; the rule is for undirected graphs, with each parent edge excluded from a child's back-edge calculation.

Counterexample to a common shortcut: Every DFS tree edge is not a bridge. The three edges of a cycle are tree/back edges under some DFS order, but none is a bridge.

2. One-use discount on a directed route

27 minutes / Chapter 24

In a directed graph with nonnegative integer edge costs, you may traverse at most one edge free of charge. Find a minimum-cost route from source s to destination t, including which edge uses the discount, or report that t is unreachable. Design an efficient algorithm. Explain why a single “best distance” at each vertex loses information and derive a rigorous time bound.

Independent input: s→a (3), a→t (9), s→b (8), b→t (4), a→b (1). Try it in the interactive lab below.

Reveal original worked solution and state argument
  1. Construct a layered directed graph with vertices (v,0) and (v,1). The second component says whether the free-edge discount has been used.
  2. For each original edge u→v of cost w≥0, add (u,0)→(v,0) of cost w, (u,0)→(v,1) of cost 0, and (u,1)→(v,1) of cost w. Start at (s,0); choose the cheaper reachable target among (t,0) and (t,1).
  3. Run Dijkstra on the expanded graph and save predecessor links, including the transition that used the discount. With a binary priority queue, the expanded graph has 2|V| vertices and at most 3|E| edges, so O((V+E) log(V+E)) time and O(V+E) storage; standard decrease-key bounds can be stated as O((V+E)log V).
  4. Every feasible original path with at most one discount corresponds to a path in the layered graph of equal cost, and every layered path projects to a feasible original walk. All transformed edges are nonnegative, so Dijkstra returns the optimum.
  5. For the independent input, the optimal path is s→a→t, discounting a→t: 3+0=3. At a, the state “coupon already used” can have cost 0, but the state “coupon still available” has cost 3 and leads to the better final answer. Keeping only the lowest cost at a would discard the latter state.

Failure cases: A negative-cost original edge invalidates the Dijkstra guarantee; an unreachable target remains unreachable in both layers. A zero-cost edge is permitted and need not consume the discount.

3. Mandatory edges across a cut

19 minutes / Chapter 23

Let G be a connected undirected integer-weighted graph. Prove that if an edge is the unique minimum-weight edge crossing some nontrivial cut (S,V−S), that edge belongs to every minimum spanning tree. Does a tie for minimum cut weight imply that no crossing edge can be mandatory? Give a careful reason or counterexample. Explain why Kruskal's algorithm can use this cut fact.

Reveal original exchange proof
  1. Let e be the unique lightest crossing edge. Suppose an MST T omits e. Adding e creates a cycle. The cycle crosses the cut at least twice, so it contains a different crossing edge f∈T.
  2. Since e is uniquely lightest, w(e)<w(f). Replace f with e; the result is again a spanning tree of strictly smaller weight, contradicting the minimality of T. Thus every MST includes e.
  3. When edges tie, the unique-edge proof fails. A four-cycle of four weight-1 edges has multiple MSTs: a cut at any one vertex has two tied crossing edges, and neither is in every MST. However, a tie alone does not prove that each tied edge is optional; other graph constraints can still force an edge.
  4. Kruskal repeatedly adds a light crossing edge of a cut respecting its current forest, so it preserves the possibility of extending its accepted edges to an MST. With sorting plus disjoint-set checks, O(E log E) time is a valid bound.

4. A new NP-completeness proof

22 minutes / Chapter 34

Define INDEPENDENT-SET as the decision problem: given an undirected graph G=(V,E) and integer k, is there a set I⊆V of at least k vertices such that no edge has both endpoints in I? Using the known NP-completeness of VERTEX-COVER, prove that INDEPENDENT-SET is NP-complete. Explicitly state the reduction direction, mapping, certificate, correctness in both directions, and running time.

This is an independent application of the lecture's Chapter 34 proof recipe. It is not presented as a specific problem shown in the instructor's slides.

Reveal original reduction proof
  1. Membership in NP: Certificate I is a list/bit-vector of at least k vertices. Verify its cardinality and scan all edges to confirm that no edge has both endpoints in I. This is polynomial (e.g., O(V+E) with a vertex-membership array).
  2. Known hard source: VERTEX-COVER, which is established as NP-complete in the Chapter 34 reduction chain.
  3. Mapping: From an instance (G,k) of VERTEX-COVER, output (G,|V|−k) of INDEPENDENT-SET. For the usual decision version with 0≤k≤|V|, this is computed in linear time; out-of-range thresholds can be handled as trivial yes/no instances.
  4. Forward: If C covers every edge and |C|≤k, then I=V\C contains no adjacent endpoints and |I|≥|V|−k.
  5. Reverse: If I is independent with |I|≥|V|−k, then C=V\I covers every edge and |C|≤k. Hence the instances have identical yes/no answers.
  6. Therefore VERTEX-COVER ≤ₚ INDEPENDENT-SET, showing NP-hardness; combined with NP membership, INDEPENDENT-SET is NP-complete.

Typical failure: Reducing the new problem to a known NP-complete problem only shows that the new problem is no harder; the needed NP-hardness direction goes from a known NP-complete source to the new target.

5. Where a factor-two guarantee comes from

14 minutes / Chapter 35

Run APPROX-VERTEX-COVER on an original star graph with center z and leaves a,b,c,d, choosing the uncovered edge (z,a) first. Give the returned cover, an optimum cover, and the ratio. Then prove that the algorithm's cover has size at most twice optimum for every undirected graph. State the role of a maximal matching (not necessarily a maximum one).

Reveal original approximation argument
  1. Picking (z,a) adds z and a to the returned cover; all four star edges are then covered. Output size is 2. The optimal cover {z} has size 1, so the ratio is 2.
  2. The algorithm repeatedly chooses an uncovered edge and adds both endpoints. Because all edges incident to selected endpoints become covered, the chosen edges are pairwise vertex-disjoint: they form a matching M.
  3. Any vertex cover C* must contain at least one endpoint of each edge in M. Since these chosen edges have no shared vertices, |C*|≥|M|. The algorithm returns 2|M| endpoints, so |C|/|C*|≤2 (for instances with at least one edge).
  4. The matching is maximal: no additional edge is disjoint from its endpoints when the algorithm stops. It need not be the matching of greatest possible cardinality. The 2-approximation proof needs disjointness, not a maximum matching oracle.

Boundary: When G has no edges, both optimum and returned covers are empty, and the approximation claim is vacuous; do not divide by zero.

Proof invariant: when Dijkstra finalizes state (v,c), its distance equals the shortest transformed path to that exact state. Compare the two distances at a vertex before merging states.

Interactive check B: is the light edge mandatory?

Try connected or disconnected undirected graphs, change the cut, and compare the unique lightest crossing edge with all minimum spanning trees for these small original practice instances. Exhaustive enumeration is a small-instance oracle, not an efficient large-graph algorithm.

The cut theorem is conditional on a connected graph. For a unique lightest edge crossing a cut, the exchange proof forces that edge into every MST. A tie blocks that strict proof but does not by itself establish a converse.

Optional cumulative and calculation drills

The historical sample contains an earlier-course technique, so do not ignore prior material completely. These independently written drills broaden preparation without claiming that any one topic will appear:

Chapter 8: use key structure instead of comparison sorting

Original practice: Sort n nonnegative integers, each less than n³, for n≥2. Explain an O(n) algorithm.

Solution: Represent each integer in base n with at most three digits. Perform stable counting sort from the least significant through the most significant digit; each digit lies in {0,…,n−1}, so each pass costs Θ(n+n)=Θ(n). Three passes yield Θ(n) total. The comparison lower bound does not apply because this is not a comparison-only algorithm. Stability matters.

Chapter 25: show one Floyd–Warshall intermediate stage

Original practice: Given p→q of weight 4, q→r of weight −2 and direct p→r of weight 6, compute the new p→r distance when q becomes an allowed intermediate, assuming no negative cycles.

Solution: min(6,4+(−2))=2. The inductive claim is that stage k considers exactly paths whose intermediate vertices are among the first k permitted vertices; time O(V³). Negative edges are allowed, negative cycles invalidate the usual finite shortest-path interpretation.

Chapter 35: distinguish two TSP arguments

Original practice: Why does doubling an MST and shortcutting prove a 2-approximation only for metric TSP? What is different in the NP-completeness reduction from Hamiltonian cycle?

Solution: In a metric, shortcutting repeated vertices never increases cost by the triangle inequality. An MST weighs no more than the optimal tour, so the doubled walk costs at most twice optimum; shortcutting preserves that bound. Chapter 34's separate decision reduction uses edge costs 0 for edges present in the input and 1 otherwise, with threshold 0; it establishes a yes/no equivalence, not an approximation bound.
