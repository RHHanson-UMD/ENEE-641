Figure 35.2 — Metric traveling salesman: MST preorder

CLRS 2nd ed., Figure 35.2; lecture slide 6. The default example uses the exact eight integer-grid points in the source figure. The graph is drawn independently.

For Euclidean points, the triangle inequality holds. Prim's algorithm constructs a minimum spanning tree (MST); preorder traversal yields a Hamiltonian tour with cost no more than twice the optimal tour.

Dashed amber edges: MST. Solid teal edges: preorder tour. Nodes are numbered in visit order.

Textbook figure — original rendering.

Proof invariant: MST cost ≤ optimum tour cost (remove one optimal tour edge to get a spanning tree). Doubling MST edges gives a closed walk of cost 2 × MST. Skipping revisited vertices cannot increase travel cost by the triangle inequality.

Lecture slides 14–15 — SUBSET-SUM FPTAS and TRIM

The optimization goal is to find the largest subset sum not exceeding t. The approximation scheme maintains sorted candidate sums, trims nearly equivalent values, and discards sums above the target.

0.40

Candidate lists after each item

    Interactive TRIM — lecture slide 14

    TRIM retains the first value in a sorted list, then discards values that are within a factor of (1 + δ) of the latest retained value. The default is the exact slide-14 list; the other lists are original practice examples.

    0.10

    The scheme chooses δ = ε/(2n), with n the number of input integers. For 0 < ε ≤ 1, the output remains within the chapter's (1+ε) approximation target. Smaller ε usually retains more intermediate candidates and costs more computation.
