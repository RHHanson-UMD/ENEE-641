Key proof obligations

A comparison decision tree with n! output permutations has height Ω(log₂n!)=Ω(n log n). COUNTING-SORT is Θ(n+k), and stable radix sorting is Θ(d(n+k)). These methods use key structure beyond pairwise comparisons. For the lecture's uniform bucket model, E[nᵢ²]=2−1/n yields expected linear time when each bucket uses insertion sort; without distribution assumptions one bucket can be quadratic.
