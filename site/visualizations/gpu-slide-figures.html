Slide 3 — four-block matrix multiplication

The instructor draws X, Y and Z partitioned into 2×2 blocks, each of size b×b where b=n/2. Four output blocks require two block products each. Select ZA, ZB, ZC or ZD to trace exactly which X and Y blocks contribute.

At the block level, the selected element is the sum of two block matrix products (not ordinary scalar products). To check the indexing numerically, the controller also substitutes an original 2×2 scalar matrix as a small independent practice example.

Slide 3 mathematical seed: Z_A=X_A Y_A+X_B Y_C; Z_B=X_A Y_B+X_B Y_D; Z_C=X_C Y_A+X_D Y_C; Z_D=X_C Y_B+X_D Y_D. The independent example sets each named block to a scalar to isolate index logic. General b×b arithmetic stays Θ(n³), while source-estimated input fetches can drop from O(n³) toward O(n³/b) when tiles fit in fast memory.

Slide 6 — historical energy-cost motivation

The lecture reproduces a copyrighted energy chart attributed to Qadeer et al. (2015). Below is a newly drawn numeric comparison using only the approximate values explicitly displayed on that slide; these are illustrative 90 nm technology values, not modern GPU/NPU/TPU benchmarks.

Why it matters: More energy can be spent retrieving instructions and moving data than on a small arithmetic operation. Special-purpose dataflow architectures can amortize instruction and data movement over many MAC operations; this chart does not establish any contemporary hardware-specific speed or energy ratio.

Slides 8–9 — preloaded-weight systolic example

These slides contain an Elsevier Figure 7.13 illustration with six weights in a 2×3 processing-element array, three staggered inputs, and two output dot products. The weights stay resident while input values pass through the array. The new diagram below uses invented weights and values, and a simple four-step schedule to demonstrate the same mathematical structure without copying the original artwork.

Highlighted PE performs a multiply–accumulate this tick; labels are zero-based row and stage indices. The timing sketch is independent and intentionally simplified.

Correctness invariant: After completing stage j in row i, the partial sum is Σk=0..j W[i,k]x[k]. When j=2, the output equals the full dot product for that row. Unlike an output-stationary 2D matrix-product array, this is a preloaded-weight 2×3 array for matrix–vector multiplication.
