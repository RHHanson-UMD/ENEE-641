CHAPTER 34 / NP-COMPLETENESS

A tour with cost zero?

The polynomial-time reduction from HAM-CYCLE to decision TSP uses a complete graph. Original edges get weight 0; missing edges get weight 1. A tour with total cost at most 0 exists exactly when the original graph has a Hamiltonian cycle.

Original graph G

Teal: best tour edges already present in the original graph. Grey: other original edges.

Complete TSP instance

Each edge is labeled 0 or 1. Amber edges form a minimum-cost tour.

Why the reduction is correct

Forward: If the original graph G has a Hamiltonian cycle, the same cycle uses only original edges in the complete weighted graph. Every selected edge has cost 0, so the tour costs 0.

Reverse: A TSP tour has n edges, each with nonnegative cost 0 or 1. If its total is at most 0, every tour edge must cost 0. Each is therefore an edge of G, making the tour a Hamiltonian cycle in G.

Complexity: Creating all n(n−1)/2 edges and assigning weights is polynomial. The exhaustive exact tour search used here is only for the small interactive demonstration; it is not the reduction algorithm and does not prove TSP can be solved efficiently.
