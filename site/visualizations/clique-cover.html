    Proof: both directions matter

    3-CNF-SAT → CLIQUE: Given a satisfying assignment, select a true literal from each clause. Their vertices connect pairwise because no variable can be simultaneously true and false. Conversely, a clique of size m (the number of clauses) chooses at most one vertex per clause, since same-clause vertices have no connecting edges. It therefore chooses exactly one from every clause. No two chosen literals contradict, so they can be extended into a satisfying assignment.

    CLIQUE → VERTEX-COVER: For any graph G with n vertices, K is a clique of size k in G if and only if V\\K is a vertex cover of size n−k in the complement graph. If two excluded vertices were adjacent in the complement, they would be a missing edge in the original clique. The reverse direction follows by the same argument.

    Polynomial growth: The clique instance contains one vertex per literal occurrence, with at most quadratically many edges; graph complementation checks at most n(n−1)/2 pairs.
