The cut property

For a connected undirected weighted graph, let A be a set of edges contained in some MST. If a cut respects A (none of the edges in A cross it), then adding a light edge crossing that cut is safe: there exists an MST containing the enlarged set. In the exchange proof, replacing a heavier crossing tree edge with that light edge preserves connectivity and cannot increase total weight.

Kruskal: The current connected components define a cut where an edge joining different components is eligible. Its edges are processed in nondecreasing order of weight. Union–find determines whether endpoints are already connected, preventing cycles.

Prim: The visited vertices and unvisited vertices define the cut. Choosing the lightest crossing edge extends the MST while preserving the cut-property invariant. Both methods output exactly n−1 edges on a connected graph. Kruskal takes O(E log E), which is O(E log V) for a simple graph; heap-based Prim takes O(E log V) with a suitable binary heap implementation.
