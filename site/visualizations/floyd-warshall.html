CHAPTER 25 / ALL-PAIRS SHORTEST PATHS

Floyd–Warshall, one intermediary at a time.

At iteration k, every shortest path is allowed to use the first k vertices as internal intermediate vertices. Advance the recursion and inspect exactly which distance entries improve. This is an original illustration, not the book's Figure 25.1.

    The dynamic programming recurrence

    D⁽ᵏ⁾[i,j] = min(D⁽ᵏ⁻¹⁾[i,j], D⁽ᵏ⁻¹⁾[i,k] + D⁽ᵏ⁻¹⁾[k,j]). A shortest path using intermediates from the first k vertices either avoids vertex k, or reaches it and then continues to its destination. This gives optimal substructure.

    Invariant: After stage k, D⁽ᵏ⁾[i,j] is the shortest distance among all i→j paths whose internal vertices belong to {1,…,k}. In the presence of a negative-weight cycle, shortest walk distances may be unbounded below, so this lesson uses graphs without negative cycles. Negative edges themselves are allowed.

    Time: O(n³) for n iterations of n² source–destination pairs. The implementation also stores snapshots for teaching; this adds O(n³) space, while a standard in-place algorithm uses O(n²) space.
