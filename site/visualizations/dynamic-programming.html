    Optimal substructure and complexity

    Matrix chain: m[i,i] = 0. For i < j, m[i,j] is the minimum over i ≤ k < j of m[i,k] + m[k+1,j] + p[i−1]p[k]p[j] using one-based notation. Optimal subchains are necessary: replacing a subchain with a cheaper parenthesization would improve the parent solution. The three nested choices give O(n³) time and O(n²) cost/split storage.

    LCS: c[i,0] = c[0,j] = 0. If xᵢ = yⱼ, then c[i,j] = c[i−1,j−1] + 1; otherwise c[i,j] = max(c[i−1,j],c[i,j−1]). The table takes O(mn) time and space. This lesson reconstructs an actual common subsequence, not just its length.
