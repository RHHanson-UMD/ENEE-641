    Invariants and the logarithmic height guarantee

    A red-black tree is a binary search tree in which every internal node is red or black, the root and all NIL leaves are black, no red node has a red child, and every path from any node to its descendant NIL leaves has the same black-node count. These conditions imply that no root-to-leaf path is more than twice as long as another and that the height is at most 2 log₂(n+1).

    Insertion first uses the ordinary BST rule, coloring the new node red. If its parent is also red, three standard cases resolve the violation: red uncle → recolor; black uncle with an inside child → rotate toward the outside case; black uncle with an outside child → recolor and rotate around the grandparent. The tree's key order is preserved by rotations.
