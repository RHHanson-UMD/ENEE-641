PRAM and the work–depth model

The slide's parallel random-access machine (PRAM) uses synchronous processors with shared memory. A pardo group performs independent instructions concurrently. Shared-memory conflict rules matter: EREW allows exclusive reads/writes, CREW permits concurrent reads, and CRCW also permits concurrent writes under an explicit resolution rule (slides 28–29).

Work W counts total operations, while depth/time T counts the longest sequence of dependent parallel rounds. Average parallelism is W/T. The slides derive the PRAM implementation bound O(W/p + T) on p processors (slide 34); this is an asymptotic upper bound, not an equality for arbitrary hardware.

The lower bound max(W/p,T) applies to this dependency/operation model. The displayed W/p+T is the theorem's upper-bound expression up to constants, not a measured runtime.

Parallel summation (slides 30–36)

At each round, independent adjacent pairs add concurrently. For n=2ᵏ input numbers, the source work–depth version counts an input-copy round of n operations, then n−1 total additions, then one output action: 2n total operations across log₂(n)+2 rounds.

Correctness: Each entry after round h is the sum of 2ʰ consecutive initial values, by induction on h. Cost: O(n) work and O(log n) depth. Try positive, negative, and single-element examples.

When parallelism helps—and when it doesn't

  • Independence: Concurrent writes to the same memory location require an explicit CRCW rule or synchronization; arbitrary simultaneous writes are not automatically deterministic.
  • Work versus depth: Less depth can require more work, as the slide-20 serial versus parallel exchange illustrates. Examine both rather than promising a speedup.
  • Associativity: Scan and reduction rely on associative operations. Integer addition works in the mathematical model; floating-point reassociation can change rounding behavior.
  • Processor limits: When p is small, W/p dominates; for sufficiently many processors, T is the dependency floor. Memory and interconnect costs are absent from this ideal PRAM model.
