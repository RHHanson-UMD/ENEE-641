Dynamic array doubling

Start with capacity one. Each append costs 1 unit to write the new value. When full, double capacity and add the cost of copying all current entries. A single append can cost Θ(n), while n appends incur O(n) total copied elements.

Proof: Resizes copy 1+2+4+⋯+2ᵏ previous elements for some 2ᵏ<n. The geometric sum is less than 2n. Thus total work from n writes plus all copies is below 3n and the amortized append cost is O(1). In accounting language, save credits from cheap appends to pay for the next resize. The precise credit schedule depends on your cost model.
