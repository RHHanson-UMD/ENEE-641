Systolic arrays: computation flows through the grid

The instructor's GPUS and TPUs 24Nov2026 deck introduces domain-specific architectures, matrix products and the possibility of NPU systolic arrays (slides 5–7). Not every NPU uses the same hardware. This page illustrates a simplified original output-stationary array; it is not the actual datapath of any commercial TPU, NPU or GPU, nor a copied slide figure.

What the processing elements do

Each processing element PE(i,j) holds an accumulator C(i,j). The A(i,k) value propagates from the left; B(k,j) propagates from the top; when the matching values arrive together, the PE executes C(i,j) ← C(i,j) + A(i,k)·B(k,j). The animation uses a carefully staggered injection schedule to make each pair arrive in the same cycle.

Check: For the default input, C=[[19,22],[43,50]]. Each output requires n multiply-accumulate updates, so a full n×n multiplication performs n³ products in this model, regardless of how the work overlaps in time.

How this relates to the GPU block model

The matrix-tiling lesson studies repeated memory fetches and tile reuse. A systolic array studies data movement through connected processing elements, which can reuse streamed operands locally instead of repeatedly fetching each multiply input from external memory. The two ideas address different layers of the same performance problem.

  • Model assumption: one PE per output, one product per active PE per tick, no stalls, zero communication cost, and a fully pipelined skewed input schedule.
  • Pipeline fill/drain: the final product reaches the far corner after the pipeline fills. The display counts 3n−2 discrete ticks for the particular original schedule; this is not a general TPU latency formula.
  • Practical limitations: tile size, on-chip SRAM, bandwidth, quantization, register precision, PE utilization, output writeback and synchronization constrain hardware throughput.
  • GPU vs NPU: GPUs offer broadly programmable parallel execution and may include specialized matrix units; NPUs emphasize neural/matrix workloads but their internal architectures vary. Systolic arrays are one architectural option, not a definition of every NPU.
