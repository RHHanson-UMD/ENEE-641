Why the approaches work

BFS: The FIFO queue processes vertices in nondecreasing distance from the source. On first discovery, setting d[v] = d[u]+1 records a path with that number of edges. Any shorter path would have first reached v from an earlier queue layer, a contradiction. Thus final distances count the minimum number of edges. Adjacency-list BFS takes O(V+E).

Topological peeling: A DAG always has a zero-indegree vertex. Removing one cannot invalidate any remaining precedence edge; repeating produces an ordering in which each directed edge u→v points forward. If vertices remain but none has indegree zero, those remaining vertices contain a directed cycle. This algorithm also takes O(V+E) with adjacency lists.
