    What the algorithms guarantee

    Relaxation: if d[u] + w(u,v) < d[v], update d[v] and set predecessor[v] = u. A finite estimate describes the cost of an actual discovered path; it remains an upper bound on the true shortest-path distance when no reachable negative cycle exists.

    Bellman–Ford: after i full rounds, all vertices with a shortest simple path containing at most i edges have their correct shortest distances. With no reachable negative cycle, a shortest path needs at most |V|−1 edges. A further improving edge detects a reachable negative cycle. Running time O(|V||E|).

    Dijkstra: if every edge has nonnegative weight, choosing the minimum tentative distance among unsettled vertices finalizes a correct distance. This implementation scans linearly to find that vertex, giving O(V²+E); a suitable priority queue improves the asymptotic bound.
